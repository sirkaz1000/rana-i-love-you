# متطلبات وتسليم A Gift For Rana

## 1. الهوية والتجربة العامة
- [x] موقع هدية إلكترونية من مروان إلى حبيبته رنا، لغته الأساسية العربية واتجاهه RTL، بتصميم رومانسي أنيق حالم وساحر وتفاعلي، ومختلف عن قالب جاهز.
- [x] أسود داكن مائل للبنفسجي، بنفسجي ملكي، وردي هادئ، أبيض لؤلؤي ولمسات ذهبية خفيفة؛ خلفية داكنة متدرجة بإضاءات بنفسجية ووردية متحركة، نجوم صغيرة متلألئة، غبار مضيء، قلوب صغيرة عائمة وبتلات ورد هادئة، مع Blur وGlassmorphism.
- [x] خطوط عربية أنيقة، وتناسق الأحجام والمسافات، وتصميم متجاوب على الهاتف واللوحي والكمبيوتر.

## 2. شاشة الدخول
- [x] تظهر شاشة مستقلة قبل المحتوى، ببطاقة زجاجية عنوانها «أهلًا بيكي يا رنا» ووصفها «وحشتيني يا حبيبة قلب مروان وروحه... فيه عالم صغير مستنيكي جواه هدية معمولة مخصوص عشانك.»
- [x] كلمة المرور المطابقة حرفيًا «حبيبة قلب مروان وروحو»، قابلة للتعديل في ملف الإعدادات؛ وزر «افتحي هديتك يا رنا».
- [x] كلمة المرور الصحيحة تفتح انتقالًا ساحرًا تدريجيًا إلى العالم الرئيسي مع قلوب ونجوم وإضاءة؛ والخاطئة تعرض «مممم... حاولي تاني يا أجمل رنا.»
- [x] قلوب خلفية، إضاءة بنفسجية حول البطاقة، حركة تركيز بسيطة لحقل الإدخال، ومؤثر صوت هادئ اختياري يمكن تعطيله.
- [x] البوابة تفاعلية وليست حماية أمنية حقيقية.

## 3. المقدمة والتنقل
- [x] بعد الدخول مقدمة سينمائية قصيرة: ظهور الخلفية تدريجيًا ثم النجوم، ثم «في وسط كل الحكايات، فيه حكاية مختلفة...» وبعدها «حكاية اسمها رنا.»
- [x] العنوان «إلى رنا... حبيبة قلب مروان وروحه»، النص «يمكن الكلام مهما كان جميل مش هيقدر يوصف مكانتك، بس حبيت أعملك حاجة تفضل تفكرك إنك مميزة عندي.» وزر «ابدئي رحلتك» ينقل بسلاسة إلى المحتوى.
- [x] أعلى الصفحة اسم رنا بتصميم أنيق، رمز قلب صغير، وشريط تنقل للأقسام.

## 4. صور رنا
- [ ] قسم بطاقات صور لثلاث صور أو أكثر، مع إمكانية إضافة عدد غير محدود بسهولة عبر ملفات الإعدادات/الأصول.
- [ ] الصور الشخصية الفعلية لرنا لم تُرفق؛ تبقى خانات الصور الثلاث جاهزة لإضافتها إلى `assets/images/` وربطها من `config.js`.
- [x] لا تستخدم صورًا عشوائية لأشخاص حقيقيين باعتبارها صور رنا. اترك أماكن مخصصة لصور المستخدم.
- [x] الصور وحدها دون أي كلام أو تعليقات أو اقتباسات أو تواريخ أو أوصاف بجانبها أو أسفلها، بما في ذلك عبارات مثل «ذكرياتنا» و«أجمل لحظاتنا» و«يوم لا يُنسى» أو ما شابه.
- [x] إطارات ذهبية أو بنفسجية رفيعة، زوايا مستديرة، ظلال ناعمة، تكبير بسيط عند المرور، فتح الصورة مكبرة عند الضغط وانتقالات جميلة بينها.

## 5. البطاقات التفاعلية
- [x] قسم بعنوان «ست حاجات من وسط حاجات كتير بحبها فيكي» بست بطاقات مستقلة ذات قلب أو رمز زخرفي، عنوان قصير، حركة مرور، وقلب عند الضغط لإظهار رسالة الظهر.
- [x] العناوين والرسائل: «ضحكتك» — «ضحكتك من الحاجات اللي ممكن تحسن يوم كامل من غير ما تحاولي.»؛ «وجودك» — «وجودك لوحده بيضيف للحياة طعم مختلف.»؛ «تفاصيلك» — «حتى التفاصيل الصغيرة اللي يمكن متاخديش بالك منها، ليها مكان خاص عندي.»؛ «عيونك» — «في حاجات جميلة كتير في الدنيا، بس عيونك ليها حكاية تانية.»؛ «قلبك» — «أجمل حاجة في الإنسان مش شكله، لكن القلب اللي بيحمله.»؛ «إنتِ» — «لأنك ببساطة رنا، وده كفاية يخلي ليكي مكانة مختلفة.»

## 6. رسالة من القلب
- [x] قسم «كلام نفسي أقولهولك» ببطاقة فخمة تشبه خطابًا شخصيًا؛ رسالة طويلة نسبيًا عاطفية وصادقة بالعامية المصرية الجميلة، دون مبالغة أو تعبيرات مبتذلة، وتظهر فقراتها تدريجيًا عند الوصول.
- [x] النص: «يا رنا، يمكن مش بعرف دايمًا أعبّر عن كل اللي جوايا بالكلام، ويمكن مهما حاولت أوصف مكانتك مش هقدر أوصل المعنى كامل. بس فيه حاجة عايزك تعرفيها، إنك مش مجرد شخص عادي في حياتي، إنتِ حبيبة قلب مروان وروحه، وليكي مكانة مميزة مش شبه أي حد. أنا بحب تفاصيلك، وبحب وجودك، وبحب الحاجات الصغيرة اللي بتخليكي إنتِ. وعشان كده حبيت أعملك الهدية دي، مش عشان مناسبة معينة، لكن عشان يكون عندك حاجة تفتحيها في أي وقت وتفتكري إن فيه حد كان حابب يرسم ابتسامة على وشك. يا رب تفضلي دايمًا مبسوطة، وتحققي كل اللي نفسك فيه، وتفضل ضحكتك منورة أيامك.»
- [x] ختم الرسالة «بكل الحب، مروان.»

## 7. أسباب تميز رنا
- [x] قسم «عارفة إيه اللي بيخليكي مميزة؟» وزر «اكتشفي» يكشف العبارات واحدة بعد الأخرى داخل بطاقات صغيرة بتأثير Fade In.
- [x] العبارات: «لأنك إنتِ، مش نسخة من أي حد.»؛ «لأن وجودك بيضيف معنى للحاجات البسيطة.»؛ «لأن ليكي تفاصيل محدش غيرك يمتلكها.»؛ «لأنك تستاهلي كل حاجة جميلة.»؛ «لأن ابتسامتك تستاهل أيام حلوة كتير.»؛ «لأن مكانتك عندي مش محتاجة مناسبة عشان أعبّر عنها.»

## 8. التاريخ والعداد
- [x] بطاقة بعنوان «من يوم ما بدأت حكايتنا...» للتاريخ المحدد بالضبط 2026/6/1، مع عرضه «01 يونيو 2026» وتحته «ومن اليوم ده والوقت بيكتب حكاية جديدة.»
- [x] عداد حي يتحدث كل ثانية ويحسب المدة الفعلية منذ التاريخ، بالسنوات والشهور والأيام والساعات والدقائق والثواني، لا أرقامًا تقريبية.

## 9. الظرف السري
- [x] بطاقة ظرف مغلق مع «فيه كلام صغير مخبيهولك...» وزر «افتحي جوابك يا رنا».
- [x] الضغط يحرك الظرف وكأنه يُفتح، ويُخرج ورقة، ويضيف إضاءة ذهبية ووردية خفيفة وقلوبًا ونجومًا صغيرة، ويظهر النص تدريجيًا كأنه يُكتب.
- [x] النص قابل للتعديل في ملف الإعدادات، ومحتواه: «إلى حبيبة قلب مروان وروحه... لو وصلتي لهنا، فعايزك تعرفي إن الهدية دي كلها اتعملت عشانك، وكل تفصيلة فيها اخترتها وأنا بفكر فيكي. يمكن الموقع مجرد شوية أكواد وألوان وصور، لكن المعنى اللي وراه أكبر بكتير. أتمنى كل مرة تفتحيه تلاقي سبب صغير يخليكي تبتسمي. خليكي دايمًا بخير يا رنا، ويا رب أيامك كلها تكون جميلة زي قلبك. من مروان... بكل الحب.»

## 10. عالم النجوم
- [x] قسم «وسط ملايين النجوم... ليكي مكانك» بخلفية فضاء ليلي ونجوم صغيرة متحركة وقلب مضيء أو نجمة كبيرة في الوسط.
- [x] عند الضغط على النجمة تظهر «مش لازم تكوني نجمة في السما عشان تنوري عالم حد... إنتِ بالفعل بتعملي كده.» وتتألّق النجوم. القسم هادئ وغير مزدحم بالمؤثرات.

## 11. الموسيقى والمؤثرات
- [x] موسيقى خلفية لملف MP3 مضبوط مسبقًا، مع مؤشر حالة وتحكم مستوى الصوت؛ تستمر الموسيقى عند الانتقال بين الأقسام ولا تعيد تشغيل الأغنية عند كل انتقال.
- [x] يبدأ الموقع محاولة التشغيل بعد قبول كلمة المرور، ويعرض حالة الموسيقى؛ لا يظهر زر تشغيل أو رفع داخل الموقع.
- [x] قلوب ونجوم وجزيئات مضيئة وبتلات ورد، ظهور عند التمرير، انتقالات بين الأقسام، Hover للبطاقات والأزرار، إضاءة خفيفة، Parallax بسيط، احتفال عند فتح الرسالة، حركة ضغط للأزرار، ومؤشر تحميل أنيق.
- [x] شريط تقدم لاستكشاف الموقع، واحترام تفضيل تقليل الحركة في إعدادات الجهاز.

## 12. التذييل
- [x] الختام يتضمن «ولو كان بإيدي أقدملك كل حاجة جميلة في الدنيا، مكنتش هتردد.» ثم «إلى رنا، حبيبة قلب مروان وروحه.» ثم «صُنعت بكل الحب، من مروان إلى رنا.» مع قلب صغير مضيء.
- [x] زر «ارجعي للبداية» يعيد الصفحة للأعلى بسلاسة.

## 13. المتطلبات التقنية والجودة
- [x] استخدام HTML5 وCSS3 وJavaScript Vanilla؛ الملفات `index.html` و`styles.css` و`script.js` و`config.js` ومجلدا `assets/images/` و`assets/audio/`.
- [x] `config.js` مسؤول عن اسم رنا واسم مروان وكلمة المرور والصور والنصوص والرسائل والتاريخ والموسيقى وعناوين البطاقات ومحتوياتها، بما يتيح تغيير المحتوى دون تعديل التصميم أو إعادة كتابة الأكواد.
- [x] كود منظم ونظيف، لا أخطاء JavaScript في Console، لا روابط أو ملفات وهمية، وجميع الأزرار ذات وظائف.
- [x] يعمل على الهواتف، سريع التحميل، يستخدم Lazy Loading للصور عند الحاجة، يراعي إمكانية الوصول، يدعم العربية وRTL، لا يعتمد خدمات مدفوعة، ويتجنب المكتبات غير الضرورية.
- [x] الشاشات الصغيرة بلا تداخل؛ وتفضيل تقليل الحركة في إعدادات الجهاز مدعوم.

## 14. ترقية المشهد الملكي والفخامة البصرية
- [x] إعادة تصميم المشهد الذي يظهر فيه الفارس راكعًا ويقبّل يد الأميرة برسوم وشخصيات وتكوين بصري أكثر جودة وأناقة.
- [x] تنفيذ حركة متقنة ومتدرجة للمشهد الرئيسي تشمل وضعيات الشخصيات، حركة اليد والانحناء، وتفاصيل بصرية تجعل اللحظة أكثر طبيعية وتأثيرًا.
- [x] إضافة عناصر وتأثيرات ثلاثية الأبعاد تمنح المشهد عمقًا وفخامة، مثل الطبقات المجسمة والإضاءة والظلال وحركة الكاميرا.
- [x] تطوير مؤثرات بصرية سينمائية تشمل الجسيمات والوهج والانعكاسات والانتقالات الناعمة من دون تشتيت الانتباه عن اللحظة الرئيسية.
- [x] رفع مستوى التصميم العام للموقع عبر تحسين التكوين البصري، التسلسل الهرمي، الخطوط، المسافات، والزخارف بما ينسجم مع الطابع الملكي الفخم.
- [x] إضافة انتقالات وتفاعلات حركية راقية بين أقسام الموقع وعند التمرير أو تحريك المؤشر.
- [x] تهيئة الرسوم والمؤثرات للعمل بسلاسة وأداء جيد، مع تخفيف التفاصيل تلقائيًا على الأجهزة الأقل قدرة.
- [x] ضمان تجربة متجاوبة ومصقولة على شاشات الجوال والأجهزة اللوحية وسطح المكتب.

## 15. تجربة الاستخدام المطلوبة
- [x] دخول رنا عبر شاشة كلمة المرور؛ قبول العبارة الصحيحة ثم فتح التجربة بصريًا.
- [x] ظهور الاسم والمقدمة والصور الشخصية؛ ثم استكشاف البطاقات والرسائل والأقسام التفاعلية.
- [x] اكتشاف التاريخ والعداد والعالم النجمي، ثم فتح الظرف السري، ثم الوصول إلى الخاتمة.
- [x] لا يُختصر أي قسم، ولا يُترك زر بلا وظيفة، ولا تستخدم نصوصًا تجريبية غير مناسبة، ولا تضاف نصوص بجانب الصور أو أسفلها.
